##Lung Capacity Prediction using Machine Learning

📌 Project Overview

This project predicts lung capacity using Machine Learning based on input features such as age, height, gender, and smoking status, depending on the dataset columns.

The project uses a trained Machine Learning model to estimate lung capacity.

🎯 Objectives

- Analyze lung capacity data.
- Understand the relationship between input features and lung capacity.
- Train a Linear Regression model.
- Predict lung capacity using user inputs.
- Build an interactive web application using Streamlit.

📂 Project Files

- "LungCapacity.csv" – Dataset used for analysis and model training.
- "lungs_cap_model.pkl" – Trained Machine Learning model.
- "app.py" – Streamlit application for prediction.
- "README.md" – Project documentation.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle
- Matplotlib (if used)

⚙️ How to Run the Project

1. Install Required Libraries

pip install pandas numpy scikit-learn streamlit matplotlib

2. Run the Streamlit Application

Keep "app.py" and "lungs_cap_model.pkl" in the correct project location.

streamlit run app.py

3. Make a Prediction

Enter the required input values in the application and click the prediction button to view the estimated lung capacity.

📊 Project Outcome

The application provides an estimated lung capacity based on the trained model and the inputs supplied by the user.

Note: This project is for educational purposes only. Predictions are not a medical diagnosis.
